## 📘 <b>Introduction</b> <br/>

<b>PrepWise</b> is an AI-powered mock interview simulator that helps candidates prepare through voice-based interaction, smart question generation, and automated feedback. <br/>

<b>Perfect for:</b> <br/>
✔️ <b>Students</b> <br/>
✔️ <b>Job seekers</b> <br/>
✔️ <b>Developers preparing for tech interviews</b> <br/>

## 🛠️ <b>Implementation (Brief Overview)</b> <br/>

### 🔊 <b>Vapi AI – Voice Interview Interaction</b> <br/>
Real-time voice conversation with an AI interviewer. <br/><br/>

### 🧠 <b>Gemini API – Smart Question Generation</b> <br/>
Creates dynamic tech, HR, and behavioral questions. <br/><br/>

### 📁 <b>Firebase – Database & Storage</b> <br/>
Stores interview history, user responses, and reports. <br/><br/>

### 🎨 <b>Sipline API – 3D Model Integration</b> <br/>
Adds animated 3D interviewer + runs processing pipelines. <br/><br/>

### 🖥️ <b>UI Layer – Next.js + Tailwind</b> <br/>
Clean, fast, and responsive interface. <br/>
